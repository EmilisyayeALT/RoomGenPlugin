# Room Gen

Roblox Studio plugin for Last Transmission: preview floors and clip-test rooms using the game's `RoomGenerator.Placement` module.

## Install

1. Clone this repo.
2. Link the plugin into your Studio plugins folder (macOS):
   `ln -s "$PWD/RoomGen.lua" ~/Documents/Roblox/Plugins/RoomGen.lua`
   (Windows: copy or `mklink` it into `%LOCALAPPDATA%\Roblox\Plugins`.)
3. Restart Studio.

## Update

`git pull`, then restart Studio.
